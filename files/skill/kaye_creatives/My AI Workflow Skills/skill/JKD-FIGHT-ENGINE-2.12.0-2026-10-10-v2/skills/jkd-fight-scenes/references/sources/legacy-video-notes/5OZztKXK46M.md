# Basic Jeet Kune Do Training (5OZztKXK46M, 5:51)
Канал: Emil Martirossian (Close Quarter Unarmed Combat Specialist, Kung Fu Technical Editor в Martial Arts Illustrated; UK).

**ВНИМАНИЕ: у видео НЕТ субтитров/транскрипта** (captions отсутствуют полностью) — конспект собран только по раскадровке (8 стрипов, шаг 5с). Это не пошаговый урок, а демонстрационный showreel тренировок JKD в трёх локациях.

**Техники по таймкодам (по кадрам):**
- 00:00–00:15 — Интро: клипы из зала — бросок/удар по красной лапе, кик по паду; ч/б вставка спарринга в зале.
- 00:20–01:30 — Рутоп-спарринг (крыша, кирпичные трубы, пасмурное небо): инструктор в чёрной футболке против партнёра в шлеме (headgear) и чёрном жилете-защите корпуса. Виден обмен: прямой lead punch в голову, защитные накладки рук, короткие входы-выходы; партнёр в защите держит высокую стойку, инструктор постоянно первым сокращает дистанцию.
- ~01:40–01:50 — Хай-кик на уровне головы (высокий круговой/hook kick) в рутоп-сете; вставка из зала с киком по паду.
- ~02:00–02:20 — Крупные планы trapping на крыше: два бойца (белая/чёрная футболки) из контакта рук — входы с контролем предплечья и ударом second-hand.
- ~02:20–02:25 — Финиш с takedown: партнёр в белом лежит на покрытии крыши, инструктор стоит над ним (контроль сверху).
- 02:30–03:45 — Зал (тёмное помещение, стоячие светлые маты-щиты, постеры Брюса Ли на стене): серия trapping / Hand Immobilization демо на разных партнёрах — pak sao + chain punches в голову, lop sao с выведением головы вниз, вход в клинч с контролем шеи, удар локтем; партнёры откидывают голову назад от каждой фиксации-удара (хорошая референс-реакция «получил»).
- 03:45–04:30 — Продолжение демо в зале: залом с наклоном партнёра вперёд (перегиб в пояснице), контроль обеих рук у лица защищающегося (двойной трап), добивание.
- 04:30–05:15 — Ч/б клипы: динамичный эпизод — партнёра сбивают/он валится через красную мебель (эффектный «падающий» кадр для хореографии); далее работа по красной focus paddle (лапа-ракетка) — скоростные прямые.
- 05:15–05:40 — Соло-скорость: удары по маленькой белой мишени на стойке (finger jab / straight punch на скорость), похоже на демонстрацию «punch felt before seen».
- 05:40–05:51 — Аутро: двое мужчин в чёрных костюмах позируют в камеру (титульная заставка).

**Визуальные детали для хореографии:**
- Три контрастных сеттинга: серая лондонская крыша (спарринг), тёмный «гаражный» зал с постерами Брюса Ли (трэппинг-демо), ч/б архив (экшн). Хороший референс для монтажа тренировочной секвенции.
- Спарринг-защита: шлем с открытым лицом + жёсткий нагрудник — можно бить в контакт; удары реально доходят, головы дёргаются.
- Дистанция в спарринге длинная (kicking/punching range) с резкими входами; в зале — trapping range, всё вяжется через контакт предплечий.
- Темп: короткие 1-2-секундные взрывные серии, между ними — восстановление стойки; в демо каждый вход заканчивается 3-5 быстрыми ударами подряд (chain punches).
- Стойка: правосторонняя on-guard, руки высоко, подбородок спрятан; удары прямолинейные, без замаха.

**Цитаты-формулировки:** нет (транскрипт отсутствует). Из описания: «Close Quarter Unarmed Combat» — ближний бой без оружия как фирменный фокус Мартиросяна.
