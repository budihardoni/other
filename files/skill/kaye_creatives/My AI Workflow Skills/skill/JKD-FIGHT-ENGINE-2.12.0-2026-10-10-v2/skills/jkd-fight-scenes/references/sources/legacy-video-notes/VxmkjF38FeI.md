# JKD ALL 27 GATES (VxmkjF38FeI, 19:19)
Канал: JKD ACADEMY OF MMA Sifu George Hajnasr (16.6K)

**Суть:** Полный каталог 27 «гейтов» (Gates / Fon Sao trapping hands) — базовых трэппинг-комбинаций JKD от контакта рук (touching hands). Гейт = «дверь»/окно для перехвата: если противник блокирует твой удар, рука не отдёргивается назад, а «ломает ворота» — иммобилизует блокирующую руку и бьёт дальше. 27 — в честь дня рождения Брюса Ли (27 ноября 1940).

**Техники по таймкодам:**
- 00:04 — Концепт: три входа — upper/middle/lower gate + outside gate. Цели по центральной линии: глаза, нос, горло, solar plexus, пах, ключица, рёбра, колено, голень.
- 01:52 — Старт всегда из touching hands (tan sao к tan sao / wu sao), стойка bai jong; из 27 гейтов можно «сделать 2000» — комбинируя.
- 03:18 — Gate 1: pak sao (push) + прямой punch, мгновенный retract. Ядро всей системы: «выучи хотя бы Gate 1 и стань им».
- 03:49 — Gate 2: тебя блокируют → lop sao снаружи + gua choy (backfist): push-punch, re-trap, hit (счёт 1-2-3-4).
- 04:25 — Gate 3: противник хватает руку изнутри → поворот в bong sao; вход изнутри: push punch, pull back, hit — «изнутри не заблокировать».
- 05:19 — Gate 4 (PIA — Progressive Indirect Attack): финт low-high, re-trap, hit; вариант low → трап вниз → выход на outside gate.
- 05:56 — Gate 5: grab → pull + punch → re-trap → punch (вариант с finger jab вместо кулака).
- 06:29 — Gate 6 «the leak»: всё запечатано → видишь щель между линиями защиты → кулак входит перевёрнутым (fist upside down) прямо в просвет, re-trap, hit.
- 07:16 — Gate 7 «running hand» (jao sao): push punch → малый круг вокруг его локтя → hit; движение очень маленькой окружностью, локоть остаётся у центра.
- 07:54 — Gate 8: рука схлопывается в elbow в лицо; пин обеих рук за локтевой сустав (не за запястье — контроль всего), возврат back hand.
- 08:30 — Gate 9: как 6, но с фейком вверх — заставить поднять руки → удар вниз в живот, re-trap, hit.
- 09:00 — Gate 10: «karate chops»: push punch, re-trap hit, pin, back hit.
- 09:30 — Gate 11: вход изнутри, punch идёт по нисходящей в leak, re-trap, hit; «иди сквозь цель, ничего не придерживай».
- 10:11 — Gates 12–13 (парой): push изнутри → grab → backhand по кругу его локтя → hit → pin down → hit. Показ с обеих сторон (смена позиций для камеры).
- 10:54 — Gate 14: headbutt — hook изнутри, втягиваешь противника в свой удар головой (1-2-3-hit).
- 11:48 — Gate 15: one-two, re-trap, hit (быстрая связка; предупреждение о травмах на скорости).
- 12:08 — Gate 16: turn + hit, re-trap, shovel hook снизу; та же позиция = arm break и takedown в пол с добиванием.
- 12:44 — Gate 17: one-two → turn (break на локте) → chop → re-trap → hit.
- 13:16 — Gate 18: блок → выход наружу, hit, re-trap, hit (1-2-3-4).
- 13:47 — Gate 19: как 7, но круг остановлен → fold его руки вниз, трап обеих рук, hit.
- 14:15 — Gate 20: локоть складывается до конца вниз, pin, апперкот снизу под подбородок.
- 14:57 — Gate 21: elbow trap тянет его вниз, шаг внутрь, удар в горло.
- 15:22 — Gate 22: push down в шею, pin его ладони прямо к его лицу, втягивание в удар коленом.
- 16:01 — Gate 23: pin большого пальца к его локтю, re-trap, pull down в колено.
- 16:33 — Gate 24: pull + finger jab → залом изнутри локтя → lock («он никуда не денется») → контроль на полу (в кадрах ~16:50–17:30 партнёр на матах, финиш сверху). Медленно ради безопасности.
- 17:16 — Gate 25: push punch, re-trap, hit с biu gee: одна рука «ослепляет» (blinds), вторая бьёт.
- 17:46 — Gate 26: jam с finger jab, re-trap hit, re-trap hit (родственник Gate 5).
- 18:17 — Gate 27 («my baby»): бесконечная цепь — pull punch, re-trap hit, chop снаружи, re-trap hit, re-trap hit... «until he's done». Финал на lightning speed.

**Визуальные детали для хореографии:**
- Сцена: два бойца в чёрных футболках, босиком, красно-синие пазл-маты, белая стена с большой эмблемой инь-ян «The Art of the Intercepting Fist».
- Дистанция: постоянный мостовой контакт предплечий (trapping range, ~30-50 см между корпусами) — почти весь ролик партнёры «приклеены» руками.
- Стойка bai jong: правая рука и правая нога впереди, задняя пятка ПОДНЯТА (лансирование вперёд перед каждым ударом).
- Темп: каждый гейт показывают 2 раза медленно + 2-3 раза «normal speed» — взрыв на 0.5-1 сек, затем полный reset в touching hands. Ритм «стук-стук-ВЗРЫВ-пауза».
- Правильное исполнение выглядит как: короткий рывок всего тела вперёд, руки размываются (сам говорит «на камеру замедляю, иначе рук не видно»), удар и мгновенный retract; без замаха, всё от центральной линии.
- Партнёры меняются ролями после каждой серии («your turn»), в конце — поклон, не отводя глаз.
