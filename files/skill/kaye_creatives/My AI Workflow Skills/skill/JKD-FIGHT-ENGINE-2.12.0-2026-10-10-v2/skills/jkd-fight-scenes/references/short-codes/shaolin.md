# Шаолиньское кунг-фу: преимущественно Shaolin Wahnam

Префикс `SHA`. Данные — [shaolin.json](shaolin.json).

### Руки, локти и удары головой

| Код | Приём / действие | Тип |
|---|---|---|
| `SHA-H1` | Чёрный тигр крадёт сердце: прямой кулак | удар / вариант |
| `SHA-H2` | Белая змея выпускает яд: высокая атака рукой | удар / вариант |
| `SHA-H3` | Драгоценная утка плывёт сквозь лотос: низкий кулак | удар / вариант |
| `SHA-H4` | Золотая звезда в углу: дуговой кулак | удар / вариант |
| `SHA-H5` | Свирепый тигр мчится по долине: прямой кулак | удар / вариант |
| `SHA-H6` | Непрерывные прямые «пушечные» кулаки | связка |
| `SHA-H7` | Тёмный дракон черпает воду: ладонь | удар / вариант |
| `SHA-H8` | Рассечь гору Хуа: диагональный рубящий удар | удар / вариант |
| `SHA-H9` | Горизонтально смести тысячу армий | удар / вариант |
| `SHA-H10` | Удар «леопардовым кулаком» | удар / вариант |
| `SHA-H11` | Удар «глазом феникса» | удар / вариант |
| `SHA-H12` | Удар ладонью «ивовый лист» | удар / вариант |
| `SHA-H13` | Ударная трактовка «тигриного когтя» | удар / вариант |
| `SHA-H14` | Золотой леопард разворачивается | удар / вариант |
| `SHA-H15` | Удар «журавлиным клювом» | удар / вариант |
| `SHA-H16` | Удар «драконьей ладонью» | удар / вариант |

### Ноги и колени

| Код | Приём / действие | Тип |
|---|---|---|
| `SHA-K1` | Счастливая птица прыгает на ветвь: боковой удар | удар / вариант |
| `SHA-K2` | Белая лошадь показывает копыто: прямой удар ногой | удар / вариант |
| `SHA-K3` | Жёлтая птица играет с водой: низкий удар ногой | удар / вариант |
| `SHA-K4` | Шаловливая обезьяна пинает дерево: дуговой удар | удар / вариант |
