# Gun-fu: постановочные эпизоды

Префикс `GF`. Данные — [gunfu.json](gunfu.json).

### Оружие и реквизит

| Код | Приём / действие | Тип |
|---|---|---|
| `GF-W1` | Экранный момент выстрела ‡ | постановочный эпизод |
| `GF-W2` | Экранная работа с парным оружейным реквизитом ‡ | постановочный эпизод |
| `GF-W3` | Переход от оружейного эпизода к рукопашному ‡ | постановочный эпизод |
| `GF-W4` | Переход от рукопашного к оружейному эпизоду ‡ | постановочный эпизод |
| `GF-W5` | Передача оружейного реквизита между руками ‡ | постановочный эпизод |
| `GF-W6` | Актёрская реакция на пустой реквизит ‡ | постановочный эпизод |
| `GF-W7` | Монтажный эпизод перезарядки ‡ | постановочный эпизод |
| `GF-W8` | Смешанный эпизод: меч и огнестрельный реквизит ‡ | постановочный эпизод |

## Чтение карточки

Для сохранённого кода читать исходный source/source_code из реестра; для нового — source_tag в выбранном разделе strike-catalogue. Имя и короткое описание не заменяют конкретную механику сцены. Школьные условия и статус источника сохраняются.
