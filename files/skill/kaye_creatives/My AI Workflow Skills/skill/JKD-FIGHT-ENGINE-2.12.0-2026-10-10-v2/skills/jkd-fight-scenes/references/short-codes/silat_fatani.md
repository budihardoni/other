# Силат: Seni Gayung Fatani

Префикс `SIL`. Данные — [silat_fatani.json](silat_fatani.json).

### Руки, локти и удары головой

| Код | Приём / действие | Тип |
|---|---|---|
| `SIL-H1` | Прямой удар кулаком | удар / вариант |
| `SIL-H2` | Хук | удар / вариант |
| `SIL-H3` | Удар ладонью | удар / вариант |

### Ноги и колени

| Код | Приём / действие | Тип |
|---|---|---|
| `SIL-K1` | Прямой удар ногой | удар / вариант |
| `SIL-K2` | Круговой удар ногой | удар / вариант |
| `SIL-K3` | Боковой удар ногой — депак | удар / вариант |

## Чтение карточки

Для сохранённого кода читать исходный source/source_code из реестра; для нового — source_tag в выбранном разделе strike-catalogue. Имя и короткое описание не заменяют конкретную механику сцены. Школьные условия и статус источника сохраняются.
