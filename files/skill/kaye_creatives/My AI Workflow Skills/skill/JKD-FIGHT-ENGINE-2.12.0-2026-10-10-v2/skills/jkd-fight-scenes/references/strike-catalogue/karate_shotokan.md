|---|---|---|---|

| Задний прямой — Gyaku-zuki | `@STRIKE_KARATE_REVERSE_PUNCH` | Кулак задней руки проходит вперёд с поворотом корпуса. | имя в источнике. Прямой противоположной передней ноге рукой; не просто любой контрудар. |

| Передний прямой — Kizami-zuki | `@STRIKE_KARATE_LEAD_JAB` | Передний кулак коротко проходит вперёд из рабочей позиции. | имя в источнике. Именованный вариант программы JKA; не тождествен JKD Straight Lead во всех деталях. |
| Восходящий удар — Age-zuki | `@STRIKE_KARATE_RISING_PUNCH` | Кулак проходит по восходящей дуге. | имя в источнике. JKA отделяет его от обычного прямого. |

| Прямой вертикальным кулаком — Tate-zuki | `@STRIKE_KARATE_VERTICAL_PUNCH` | Кулак проходит прямо с вертикальной ориентацией кисти. | имя в источнике. Вариант ориентации ударной поверхности. |

| Двойной параллельный прямой — Morote-zuki | `@STRIKE_KARATE_DOUBLE_PARALLEL_PUNCH` | Оба кулака одновременно выходят вперёд параллельными линиями. | имя в источнике. Одно двуручное действие, не два отдельных последовательных удара. |
| Двойной прямой с обращёнными ладонями — Awase-zuki | `@STRIKE_KARATE_DOUBLE_FACING_PUNCH` | Два кулака одновременно выходят вперёд ладонями друг к другу. | имя в источнике. Вариант ориентации двойного удара; не синоним Morote во всех деталях. |
| Двойной удар «гора» — Yama-zuki | `@STRIKE_KARATE_MOUNTAIN_PUNCH` | Два кулака одновременно выходят на разнесённых линиях. | имя в источнике. Характерная двуручная форма; источник называет её Triangle Punch. |
| Двойной сходящийся удар — Hasami-zuki | `@STRIKE_KARATE_SCISSOR_PUNCH` | Два кулака одновременно сходятся по круговым линиям. | имя в источнике. Отдельная двуручная траектория, а не произвольная серия. |
| Обратный удар кулаком — Uraken-uchi | `@STRIKE_KARATE_BACKFIST` | Тыльная сторона кулака проходит короткой дугой. | имя в источнике. Вертикальное или боковое исполнение задаётся вариантом. |
| Удар кулаком-молотом — Kentsui / Tetsui-uchi | `@STRIKE_KARATE_HAMMERFIST` | Нижний край закрытого кулака выполняет рубящее движение. | имя в источнике. Kentsui/Tetsui/Tettsui — варианты имени, а не три техники. |
| Локоть снизу вверх — Tate-enpi | `@STRIKE_KARATE_RISING_ELBOW` | Локоть проходит по вертикальной восходящей линии. | имя в источнике. Именованное направление Enpi; не путать с названием ката Enpi. |
| Боковой локоть — Yoko-enpi | `@STRIKE_KARATE_SIDE_ELBOW` | Локоть выходит к партнёру в сторону. | имя в источнике. Отдельное боковое направление локтевой семьи. |
| Локоть назад — Ushiro-enpi | `@STRIKE_KARATE_BACK_ELBOW` | Локоть выходит назад короткой линией. | имя в источнике. Направление назад; разворот не обязателен для базового имени. |
| Локоть сверху вниз — Otoshi-enpi | `@STRIKE_KARATE_DOWNWARD_ELBOW` | Локоть проходит сверху вниз. | имя в источнике. Именованное нисходящее направление. |
| Круговой локоть — Mawashi-enpi | `@STRIKE_KARATE_ROUND_ELBOW` | Локоть проходит по горизонтальной круговой дуге. | имя в источнике. Круговое направление отличается от прямого бокового выхода. |
| Фронтальный кик — Mae-geri | `@STRIKE_KARATE_FRONT_KICK` | Стопа проходит вперёд по фронтальной линии. | имя в источнике. Базовая семья; поверхность и snap/thrust задаются отдельно. |
| Фронтальный кик передней ногой — Kizami-maegeri | `@STRIKE_KARATE_LEAD_FRONT_KICK` | Передняя стопа коротко проходит вперёд. | имя в источнике. Именованный вариант передней ноги по программе JKA; левое/правое не получают отдельных тегов. |
| Хлёсткий боковой кик — Yoko-geri keage | `@STRIKE_KARATE_SIDE_SNAP_KICK` | Стопа выполняет боковой хлёсткий выход с возвратом. | имя в источнике. JKA явно отличает Keage от Kekomi; боковая семья без дублирующей общей записи. |
| Толчковый боковой кик — Yoko-geri kekomi | `@STRIKE_KARATE_SIDE_THRUST_KICK` | Стопа выдвигается в сторону по прямой линии. | имя в источнике. Прямой боковой толчковый вариант, не Keage. |
| Круговой кик — Mawashi-geri | `@STRIKE_KARATE_ROUNDHOUSE_KICK` | Стопа проходит к партнёру по круговой боковой дуге. | имя в источнике. Именованная базовая семья, подтверждённая экзаменационной программой. |
| Задний прямой кик — Ushiro-geri | `@STRIKE_KARATE_BACK_KICK` | Пятка выходит назад по прямой линии. | имя в источнике. Разворот может предшествовать удару, но не создаёт обязательной круговой траектории. |
| Дуговой кик-полумесяц — Mikazuki-geri | `@STRIKE_KARATE_CRESCENT_KICK` | Стопа проходит по широкой дуге-полумесяцу. | имя в источнике. Имя школьного словаря; внутреннее/внешнее направление не выдано за две прямо названные там техники. |
| Обратный круговой кик — Gyaku mawashi-geri | `@STRIKE_KARATE_REVERSE_ROUND_KICK` | Стопа проходит по круговой дуге в обратную сторону. | имя в источнике. Использовано имя Sochin; соответствие Ura-mawashi других школ уточняется эталоном. |
| Обратный круговой кик с разворотом — Ushiro mawashi-geri | `@STRIKE_KARATE_SPINNING_REVERSE_ROUND_KICK` | После разворота стопа проходит по обратной круговой дуге. | имя в источнике. Отличается от прямого Ushiro-geri. |
| Топчущий кик — Fumikomi-geri | `@STRIKE_KARATE_STAMP_KICK` | Подошва или наружный край стопы проходит вниз по топчущей линии. | имя в источнике. Поверхность и игровая цель выбираются сценой. |
| Удар коленом — Hiza-geri / Hizazuchi | `@STRIKE_KARATE_KNEE_STRIKE` | Колено выходит к партнёру на близкой дистанции. | имя в источнике. Hiza-geri в glossary и обозначение поверхности в JKA сведены в одну семью. |
| Фронтальный кик в прыжке — Tobi mae-geri | `@STRIKE_KARATE_JUMP_FRONT_KICK` | Стопа проходит вперёд во время прыжка. | вариант семейства. Авторский вариант именованной семьи Tobi-geri; конкретное сочетание не перечислено дословно в использованном glossary. |
| Боковой кик в прыжке — Tobi yoko-geri | `@STRIKE_KARATE_JUMP_SIDE_KICK` | Стопа выдвигается в сторону во время прыжка. | вариант семейства. Вариант общей семьи Tobi-geri, не новый базовый стиль. |

## Источники и границы

- [Japan Karate Association — Technical Manual for the Instructor](https://www.jka.or.jp/wp/wp-content/uploads/2017/04/tech_manual_instructor.pdf) — 6.10.2026 прочитаны первичные разделы Punches pp22–23, hands pp17–18, feet p19, Uraken/Yoko-geri pp31–32 и Enpi p33. Имена10 форм tsuki, hand surfaces и пяти направлений enpi подтверждены текстом.
- [English Goju-Ryu Karate-Do Association — own glossary](https://egka.org.uk/glossary/) — 6.10.2026 прочитаны Punches/Strikes/Kicking: tsuki, shuto/teisho/haito/hiraken/ko/nukite/tetsui/enpi, mawashi/ushiro/hiza/kensetsu geri. Это Goju-ryu glossary, не все Okinawan школы.
- [Sochin Karate Club — own Shotokan terminology](https://www.sochinkarateclub.co.uk/shotokan-kata/shotokan-terminology/) — 6.10.2026 живой школьный HTML прочитан обычным HTTP после timeout web-reader: ren-zuki, mikazukigeri, gyaku mawashigeri, ushiro mawashigeri, fumikomigeri и tobi-geri. Это названия данной школы.
- [Japan Karate Association — Kyu/Dan Grading Guideline (2017 English document)](https://www.jka.or.jp/wp/wp-content/uploads/2017/06/b98c5e1514acc9fe91bbbc4b2fcb79f2.pdf) — 6.10.2026 прочитан первичный учебный PDF: Kizami-zuki, Kizami-maegeri, Mawashi-geri, Ushiro-geri, Sanbon-renzuki и Ren-geri.
