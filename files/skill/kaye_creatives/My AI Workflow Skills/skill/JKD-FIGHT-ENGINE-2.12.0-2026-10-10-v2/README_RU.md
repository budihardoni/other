# JKD FIGHT ENGINE — пакет для передачи

Версия скилла: 2.12.0. Дата экспорта: 10 октября 2026.

Внутри: основной jkd-fight-scenes, шпаргалка jkd-moves, полный ULTRALORDGEN v2.9, карточки и реестры движений, материалы исследования, исходные assets скилла и инструкция настройки выдачи. Реестр содержит 736 канонических кодов в 44 разделах; это не заявление о полном охвате всех мировых боевых искусств или просмотре всех фильмов.

## Установка

1. Распакуйте ZIP целиком.
2. Для Codex скопируйте три папки из skills в ваш $CODEX_HOME/skills (обычно ~/.codex/skills). jkd-fight-scenes и jkd-moves должны лежать рядом. Не заменяйте уже установленную папку без сохранения её собственной версии. Скиллы станут доступны после обновления среды; начните новый чат, если текущий ещё не видит их.
3. Для другой среды с поддержкой файловых skills импортируйте папки целиком её штатным способом. Один SKILL.md без references и assets не содержит всю библиотеку.
4. Начните с /jkd-moves или запроса «Покажи коды бокса». Для промптов также подключите включённый ULTRALORDGEN. Настройка постоянного генборда описана в skills/jkd-fight-scenes/references/portable-installation.md; integrations/viktor-genboard-style — инструкция для такой настройки, а не готовый сервер.

## Вызовы

- /jkd-moves — полный список кодов.
- «Покажи все коды Муай-Тай» — один раздел.
- «Раскрой BOX-H6: движение, контакт, реакция, усилие тела и мимика» — карточка выбранного движения.
- «JKD: H1 → T5 → K2» — последовательность в указанном порядке.
- «Связка BOX-H1 → BOX-H3 → MT-K1» — смешанная последовательность с префиксом у каждого движения.
- «Разбери этот фрагмент в режиме RECONSTRUCT» — анализ конкретного предоставленного видеореференса.

Для точного поиска при наличии Python 3 доступен scripts/short_codes.py внутри jkd-fight-scenes: команды list, show BOX-H6, resolve BOX-H1 MT-K1 WC-H1. Скрипт использует стандартную библиотеку и не требует установки пакетов.

## Состав и пределы

Проверены целостность ZIP, структура навыков, доступность определений всех 736 кодов, все зарегистрированные алиасы и сохранение порядка смешанной связки. Это проверка упаковки и справочника, а не новый аудит видеоматериалов или успешная генерация.

SOURCE_ARCHIVE/ в исследовательских карточках обозначает прежние внешние исходники, не включённые в архив. Их отсутствие явно описано в portable-installation.md; исторические статусы проверок сохраняются. Локальные проекты, библиотека превизов, аккаунты, секреты и живой Hub не передаются. Включены только файлы самого скилла и небольшие связанные методические отчёты.

MANIFEST.json фиксирует происхождение файлов, контрольные суммы и изменения экспортной копии. CHECKSUMS.sha256 позволяет проверить распакованные файлы. Оригинальные установленные скиллы не изменены.
